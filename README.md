# SS14.Android

Android-лаунчер для серверов Space Station 14: список серверов, вход в аккаунт, загрузка движка и контента, запуск игры с сенсорным управлением.

| Папка | Что это |
|---|---|
| `Robust.Client.Android` | APK: интерфейс лаунчера, процесс игры (SDL3), нативные библиотеки, AOT |
| `Robust.Launcher.Core` | хаб, авторизация, загрузка движка, контента и среды .NET |
| `Robust.Android.GameHost` | точка входа в процессе игры, запускает движок |
| `Robust.Launcher.Cli` | тот же лаунчер в консоли, для проверки на ПК |
| `Robust.LoaderApi` | интерфейс загрузчика движка (сабмодуль) |

Движок в этой ветке не хранится: лаунчер скачивает Android-сборку нужной версии из релизов или официальную сборку в режиме совместимости. Подробности — в [Robust.Client.Android/README.md](Robust.Client.Android/README.md).
